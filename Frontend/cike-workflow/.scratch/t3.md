## Parent

#23 — 完善工作流实例列表功能

## What to build

给实例列表加上三类彼此正交、AND 叠加的筛选，外加两个开关，让用户能精确收窄到关心的实例子集。独立可演示。

范围：
- **自由文本搜索** → `searchTerm`。占位提示如实反映后端匹配范围（实例名称 / 关联 ID / 实例 ID；后端 searchTerm **不匹配定义名**）。
- **工作流定义筛选** → 可搜索 combobox（`shadcn-vue add command`），选项数据源 `getApiV1WorkflowDefinitionsOptionList({ query:{ workspaceId } })`（跨目录全量 `{definitionId,name}[]`），选中传 `definitionIds`。**不得**用 `Definitions/List`（按单 folderId 严格过滤）。
- **状态筛选** → 一排可多选 chips（`shadcn-vue add toggle-group`，`type="multiple"`），选中集合传 `workflowStatuses[]`，配色沿用 `statusConfig`。**严禁 `workflowMainStatuses`（ADR-0012）**。
- **"只看有异常"开关** → `hasIncidents=true`。
- **"显示调试实例"开关** → 关(默认)传 `isDebug=false`、开传 `isDebug=true`；二者不可混看（后端 `??=false`）。调试视图下每行加"调试"徽标。
- 表格中**点定义名即按该定义筛选**（写入 `definitionIds` 并重查）。
- 任一筛选变更 → 页码归 1 重查。
- "筛选无命中"空态（有实例但当前筛选 total=0）+ "清除筛选"按钮（复位全部筛选并重查）。

关键代码（决策承载，源自原型）：

`buildFilter()` —— ADR-0012 护栏 + isDebug 永远显式：

```ts
function buildFilter(): WorkflowInstanceFilter {
  const filter: WorkflowInstanceFilter = { workspaceId, isDebug: isDebug.value }
  const term = searchTerm.value.trim(); if (term) filter.searchTerm = term
  if (selectedStatuses.value.length) filter.workflowStatuses = [...selectedStatuses.value]
  if (selectedDefinitionIds.value.length) filter.definitionIds = [...selectedDefinitionIds.value]
  if (hasIncidents.value) filter.hasIncidents = true
  return filter // ← 绝不出现 workflowMainStatuses（后端 GetMainStatus 遇 Interrupted 抛异常）
}
```

筛选变更归位第 1 页 + 空态二分：

```ts
function applyFilters() { page.value = 1; return fetch() }
const hasActiveFilters = computed(() =>
  searchTerm.value.trim() !== "" || selectedStatuses.value.length > 0 ||
  selectedDefinitionIds.value.length > 0 || hasIncidents.value || isDebug.value)
const isFilteredEmpty = computed(() => !loading.value && !loadError.value && total.value === 0 && hasActiveFilters.value)
function clearFilters() { /* 复位全部筛选 ref */ page.value = 1; return fetch() }
```

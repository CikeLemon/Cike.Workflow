# CONTEXT — Cike Workflow 领域术语表

> 本文件是**术语表（glossary）**，只定义领域概念与它们之间的关系，不含实现细节、文件路径或代码。

## 工作流定义（Workflow Definition）

一个可被反复实例化执行的流程蓝图。对外有两个标识需区分：

- **业务 ID（definitionId）**：字符串，跨所有版本恒定，标识"同一个定义"。
- **版本行 ID（version row id）**：int64，标识"某个定义的某一个具体版本"。API 路径参数 `{id}` 指的是**版本行 ID**，不是业务 ID。

## 版本（Version）

工作流定义的一次内容快照，带递增的**版本号（version）**。每个版本行有两个正交状态：

- **最新版本（Latest）**：`isLatest = true` 的那一行。一个定义只有一个最新版本，它是编辑操作的落点。
- **已发布版本（Published）**：`isPublished = true` 的版本。**已发布版本是不可修改的**——它是一个冻结的快照。

由上述两条派生出两类可能的"最新版本"形态：

- **草稿最新版本（Draft Latest）**：`isLatest = true 且 isPublished = false`。可以就地保存修改。
- **已发布最新版本（Published Latest）**：`isLatest = true 且 isPublished = true`。不能就地修改；对其保存会**派生出一个新的草稿版本**（见"保存"）。

## 画布内容（Canvas Content）

一个工作流版本的可编辑主体，由两部分组成：

- **根活动（Root Activity）**：活动树的根节点，承载画布上的节点与连线（含嵌套容器）。
- **选项（Options）**：版本级配置，由**工作流变量（Variables）**、**工作流输入（Inputs）**、**工作流输出（Outputs）**、**工作流结果（Outcomes）**与**自定义属性（Custom Properties）**组成；其中自定义属性是后端预留的扩展载荷，不属于用户显式配置项。变量、输入、输出、结果各自拥有独立名称空间：同类名称必须唯一，不同类别允许同名。

## 连接（Connection）

同一画布上两个活动之间的有向控制流链接：源是源活动的某个**出端口**（默认端口可省略），目标恒为靶活动的唯一**入端口**。是画布内容的一等成员，可被单独选中与删除，也是插入节点操作的承载对象。
_Avoid_: 边、edge、跳转线

## 插入节点（Edge Insertion）

在一条既有连接的中部插入一个新活动的编辑操作：移除原连接、加入新节点、并按「源 → 新节点、新节点**首个出口** → 原目标」重接；两端空隙放不下新节点时，原目标的结构下游按需右移腾位。整次插入是一个不可分割的撤销步。
_Avoid_: 中间加节点、插队

## 工作流输入（Workflow Input）

工作流对调用方声明的具名入参，包含数据类型、是否数组、显示信息、默认表达式与存储方式。调用方未传递该名称时，运行时求值其默认表达式作为输入值；显式传入 `null` 视为有效输入，不触发默认值。输入默认表达式只允许 Literal、Liquid、JavaScript，不允许引用其他工作流输入或变量。

## 工作流输出（Workflow Output）

工作流对调用方声明的具名返回项，包含数据类型、是否数组、显示信息与默认表达式。工作流正常完成且未写入该名称时，运行时求值其默认表达式作为输出值；显式写入 `null` 视为有效输出，不触发默认值。取消或故障终态不补默认输出。输出默认表达式允许 Literal、Liquid、JavaScript、Input、Variable 五类，可读取工作流最终的输入与变量。

## 工作流结果（Workflow Outcome）

工作流完成时可能产生的具名结果，用于调用该工作流的上层流程进行后续路径选择。它描述控制流分支，不等同于承载数据的工作流输出。

## 活动（Activity）

画布上的一个节点，代表流程中的一个步骤（如开始、条件分支、HTTP 请求等）。**容器活动（Container Activity）**可包含子活动，支持**下钻（Drill）**进入其内部画布。

## 节点 Id（NodeId）

活动在工作流树中的层级结构身份，由根到该活动的路径唯一确定：以「父节点 NodeId + 自身活动 Id」逐级拼接而成（根节点即自身活动 Id）。**活动 Id** 是实例身份、创建即生成；**NodeId** 是结构路径身份，二者不可混用。后端在物化时赋值；前端设计器在新增节点时按同一规则计算、并在加载既有画布时回填，两侧算法必须一致。

## 设计器（Designer）/ 画布（Canvas）

编辑工作流定义画布内容的可视化界面。画布有两种模式：

- **可编辑模式**：用于编辑最新版本。
- **只读模式（Read-only）**：用于查看历史版本内容或工作流实例的运行轨迹，不允许改动。

## 画布校验（Canvas Validation）

对当前画布内容（画布根 + 变量）运行的严格正确性检查，与发布前置校验共用同一套规则（开始节点、孤立节点、连线引用、必填输入、变量合法性），递归整棵活动树。只读、不落库、不产生版本；产出一组**校验问题**，空集合即通过。规则的唯一真源在后端，前端不复制。

## 问题清单（Problem List）

设计器画布下方停靠的可折叠面板，是画布校验所产出问题的唯一呈现出口。每条**校验问题**带定位信息（活动 Id / 节点 Id / 名称；工作流级问题如变量非法则为空）与消息，全部为错误级、无警告分级。点击可定位的问题会下钻到该节点所在容器层并选中高亮，同时在画布上给对应节点打错误标记；工作流级问题只展示、不跳转。

## 停靠面板（Dock Panel）

设计器画布周边的可折叠工作区：左侧为**活动面板**，底部为**问题清单**，右侧为只显示一个内容面板的**右侧工具区**。右侧工具区包含**工作流配置**与**节点属性**两个入口；未选中节点时默认显示工作流配置，选中节点时自动切换到节点属性。每个停靠区域有两个正交状态：**展开/折叠** 与 **固定（Pin）**。

## 固定（Pin）

停靠面板的常驻锁定状态。跨会话持久化的内容是 **pin 标志 + 被 pin 时的展开/折叠状态**；未 pin 的展开/折叠状态仅会话级。被 pin 的面板免疫一切被动自动展开/自动收起。仲裁准则：**被动自动行为服从 pin**（pin 折叠不因新问题出现而自动展开，pin 展开不因校验通过而自动收起）；**用户自身动作发起的揭示优先于 pin**（如发布被拦截时的强制展开）。

## 自动隐藏（Auto-hide）

未 pin 的停靠区域根据内容与当前上下文的相关性自动切换或开合。活动面板无自动隐藏；右侧工具区在选中节点时切到节点属性并自动展开，取消选中时切回工作流配置且保持当前展开/折叠状态；问题清单在问题数 0→N 时自动展开、N→0 时自动收起、N→M 时保持手动状态。自动行为只在转变时刻触发，中途不与用户的手动状态打架。

## 保存（Save）

把当前画布内容（根活动 + 选项）持久化到**当前打开的版本行**。语义随版本状态分叉：

- 当前是**草稿最新版本**：就地更新该行，版本号不变。
- 当前是**已发布版本**：由于已发布版本不可修改，后端会**派生出一个新的草稿版本并返回其新版本行 ID**；此时前端必须**按新版本行 ID 重新加载整个画布**，之后的编辑落在这个新草稿上。

## 发布（Publish）

把一份画布内容（根活动 + 选项 + 可选**发布备注 publishedNote**）提交为一个已发布版本。发布是一次性提交画布内容的动作，不要求先单独保存。

## 回滚（Rollback）

以某个历史版本为源，使其内容成为新的最新版本。用**业务 ID + 目标版本行 ID**定位来源。

## 工作流实例（Workflow Instance）

工作流定义某一版本的一次具体执行。实例**归属于其定义所在的工作空间**，实例列表按工作空间作用域取数。实例引用它执行时所依据的**定义版本行 ID（definitionVersionId）**。

实例带**运行状态（Status）**，共七种：等待中（Pending）/ 执行中（Executing）/ 已挂起（Suspended）/ 已完成（Finished）/ 已取消（Cancelled）/ 已故障（Faulted）/ 已中断（Interrupted）。其中前六种按**主状态（Main Status）**归为两组：**运行态（Running）** = 等待中 / 执行中 / 已挂起；**终态（Finished）** = 已完成 / 已取消 / 已故障。（已中断在运行时未被归入任一主状态，属已知缺口，见相应 ADR。）

## 子工作流实例（Sub-workflow Instance）

由另一个工作流实例在其执行过程中触发产生的实例，带有指向触发者的**父实例（Parent Instance）**。列表中以角标标识其为子流程。

## 取消（Cancel）

对一个**运行态**实例发出的终止动作，请求结束其后续执行。取消**不可撤销**——一旦取消无法恢复运行，因此属于需要用户明确确认的破坏性操作。取消是**异步**的：请求被接受时状态尚未翻转，需重新查询才能观察到已取消；对**非运行态**实例取消无效果（幂等忽略）。取消只终止执行，**不删除实例记录**（实例无删除能力）。
_Avoid_: 停止、终止、删除

## 活动执行记录（Activity Instance Execution Record）

工作流实例中某个活动的一次执行痕迹。通过 **activityId** 与画布上的活动节点对应，带**活动状态（ActivityStatus）**：Pending / Running / Completed / Canceled / Faulted。用于在画布上标记"流程运行到了哪里"。

# 调试（Debug Run）

对**草稿版本行**发起的试跑：从开始节点启动，实例标记 `IsDebug = true`，副作用真实发生。调试前自动保存当前画布内容（所见即所跑）；已发布版本不能直接调试。调试发起后在**新标签页**打开实例详情，设计器保持不动，支持"改 → 调 → 看 → 再改"的迭代循环。调试实例默认不出现在实例列表中。
_Avoid_: 试运行、执行

## 调试输入（Debug Input）

调试发起时用户可填写的工作流输入键值对。始终弹出输入弹窗（即使工作流无输入声明，也作为确认步骤）。Literal 类型的默认表达式预填字面值；非 Literal 类型留空并以 placeholder 展示表达式摘要，不填则不传该 key、由后端求值默认表达式。

## 执行进度事件（Execution Progress Event）

经 SignalR 实时推送的节点级/实例级状态变化通知。节点级四种：ActivityStarted / ActivityCompleted / ActivitySuspended / ActivityFaulted；实例终态四种：WorkflowFinished / WorkflowSuspended / WorkflowFaulted / WorkflowCanceled。载荷携带 ActivityNodeId 与 ActivityInstanceId，可直接映射到画布节点。应用级维护单条 SignalR 连接，进入实例详情时 Watch（加入实例分组），离开时 Unwatch。
_Avoid_: WebSocket 消息、推送通知

## 实例概览（Instance Overview）

实例详情页右侧工具区在**未选中节点**时展示的面板：实例状态、工作流输入、工作流输出、关联 ID 与创建时间等元信息。与节点执行详情互斥切换，复用设计器右侧工具区的 Pin/折叠/展开机制。

## 节点执行详情（Activity Execution Detail）

实例详情页右侧工具区在**选中节点**时展示的面板：活动名称 + 类型 + 状态徽标、activityState 与 outputs 的 JSON 树形只读展示、执行日志区域。循环体内同一节点有多条执行记录时，取最新一条展示。
_Avoid_: 节点属性、活动面板

## 表达式（Expression）

活动输入所承载的"如何得到值"的描述，形如 { 类型, 值 }；**值的具体含义由类型决定**，同一字段在不同类型下值的形态完全不同。
_Avoid_: 值、参数值

## 表达式类型（Expression Type）

决定表达式的值如何被求值的类别。后端注册五种并经 ExpressionDescriptors 端点动态暴露：**Literal / JavaScript / Liquid / Variable / WorkflowInput**。
_Avoid_: 语法、语言

## 字面量表达式（Literal）

值即最终值本身，且是**具体的、带类型的值**——与所属输入的目标类型一致（数字输入即数字、字符串输入即字符串、布尔即布尔）。不存在"空即 null"的形态。
_Avoid_: 常量、固定值

## 脚本/模板表达式（JavaScript / Liquid）

值是**源码文本字符串**：JavaScript 为待执行脚本，Liquid 为待渲染模板；运行时求值/渲染后再转换为目标类型。
_Avoid_: 代码块

## 引用表达式（Variable / WorkflowInput）

值是一个**名字字符串**，运行时按名字解析到工作流级变量定义 / 工作流输入定义；不存定义对象快照。
_Avoid_: 绑定、指针

## 输入（Input）

活动的一个可编辑参数，包装一个表达式（及内存块引用）；其**目标类型**决定该输入在 Literal 下值的具体类型。
_Avoid_: 字段、属性

## 输出（Output）

活动的一个具名产出，包装一个**内存块引用**而**不含表达式**——输出是「往内存块写值」，与输入的「求值取值」方向相反。运行时活动把产出值写入其内存块。输出**默认未绑定**（不携带具体引用），此时产出值不落入任何持久位置；被**绑定**后，产出值写入绑定目标。区别于**工作流输出**（后者是工作流对调用方声明的具名返回项，属版本级配置）。
_Avoid_: 返回值、字段

## 输出绑定（Output Binding）

把一个活动的输出连接到某个**变量**，使该输出的产出值落入这个变量。绑定的本质是「让输出的内存块标识与目标变量的标识一致」，因此绑定是按标识对齐、而非按名称——变量改名不影响已建立的绑定。一个输出同一时刻至多绑定一个目标；未绑定即回到默认状态。
_Avoid_: 赋值、映射到字段

## 表达式编辑器（Expression Editor）

编辑某个输入之表达式的统一界面：类型选择器 + 各非字面量类型的通用编辑器；**字面量的值编辑交由所属节点自行提供**（因为只有节点知道输入的目标类型）。
_Avoid_: 输入框、表单控件

## 条件（Condition）

一个求值为真/假的表达式，用于决定控制流走哪条分支。**If 的条件与 Switch 每个分支的条件是同一个概念**，共用同一套编辑方式。
_Avoid_: 判断、布尔表达式

## 分支（Case）

Switch 的一个出口，由一个**出端口名（label）**与一个**条件**组成：条件为真即命中该分支。Switch **不含"被匹配的值（Subject）"**——它是规则式多分支条件，而非值匹配。
_Avoid_: 选项、匹配值

## 匹配模式（Switch Mode）

Switch 在多个分支条件同时为真时的取舍策略，两种：**首个优先（MatchFirst）**——自上而下第一个为真的分支胜出；**匹配所有（MatchAny）**——所有为真的分支都触发。
_Avoid_: 匹配策略、比较模式

## 默认分支（Default）

Switch 中所有分支条件都不命中时所走的固定出口。
_Avoid_: 兜底分支、else

## 条件组（Condition Group）

条件的结构化形态：一排**比较**用同一个逻辑操作符（且/或）接合，并可再按该操作符接合**一个内缩的子条件组**；子组递归同形状。组上的操作符同时接合"本排比较"与"子组"两者。
_Avoid_: 条件树、AST

## 比较（Comparison）

条件组中的一行原子判断：**左操作数 运算符 右操作数**，求值为真/假。是条件组的最小成员。
_Avoid_: 规则、过滤项

## 操作数（Operand）

比较的左/右取值，本身是一个带**数据类型**的值：字面量（按字符串/数字/布尔/日期时间渲染不同控件）或一段脚本。
_Avoid_: 参数、字段
